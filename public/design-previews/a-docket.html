StackBrief — the architectural brief before a code change.

Problem
Before an edit, a developer or coding agent has to rebuild the system in their head. READMEs drift, and the architecture is spread across routes, services and manifests.
Constraints
No account, API key or network. Must run on Node 16.7+. It's static analysis, so it has to say what it can't prove.
Built
A scanner that writes a deterministic stackbrief.json, a typed knowledge layer, and a brief renderer that cites file and line for every claim.
Stack
  • TypeScript
  • Node.js CLI
  • 7 packages
  • Schema v2
  • Agent layer: portable pre-change skill
