Admon

Turns public GitHub activity into a wallet-owned build record, minted on Monad Mainnet.

Problem
Anyone can claim a GitHub profile. A build record is only worth something if the person minting it actually controls that profile.
Constraints
One record per GitHub username. No private keys in the browser. Traits must be reproducible from public data.
Built
GitHub OAuth proof of control, deterministic trait derivation, Postgres persistence, and short-lived EIP-712 mint authorisations signed server-side.
